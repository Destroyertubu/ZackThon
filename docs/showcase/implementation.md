# 天地人评委演示：实现与验收记录

## 使用与交付

独立控制台：[打开一键录制入口](https://range-diploma-exams-jones.trycloudflare.com/showcase)。直接打开网址，点击“生成演示视频”。页面显示镜头进度，可取消；失败时显示具体步骤，可重新生成。关闭页面不会中止服务器录制。此地址使用现有方式运行独立公网隧道，隧道重建后地址可能变化。

每次完整任务输出 180 秒、1920×1080、30 FPS 的 H.264/AAC 视频：带中文字幕版、无字幕版，以及旁白 WAV、SRT、星海收尾 PNG 和介绍文稿。最后五秒使用同一幅星海画面，不添加额外片尾时长。

## 真实操作与数据隔离

八个镜头共享同一个任务专用 Firefox profile，调用现有阅读、收藏、批注、足迹、星树、小屋和调酒逻辑。每一步等待 React 和个人存储确认；失败镜头重试一次，仍失败则停止产片，保留失败步骤。

演示使用仓库已有公开快照中的窦泽南作品《拯救注意力分散：使专注力提升，反馈给学习行动效力》，保留“知识作品节选”身份。实际选择引文“到安静的户外，听听自然”，写入演示者手记“用照片和文字，记录一次户外的专注。”。后续场景校验同一来源与手记身份；调酒时由真实选项带入该笔记。

录制服务仅使用快照和独立内存内容库，拒绝实时上游请求；容器没有外网、没有真实玩家浏览器卷。每次录制重新建立个人空间。批注片段重试仅撤回当前演示收藏和完全匹配的演示批注，不删除其他记录。

场景预热在正式镜头之前完成。落日大道通过专用只读场景路由预热；这一步不挂载创建旅程的页面，并断言旅程数量不变。正式镜头仍通过调酒动画及现有自动传送创建旅程。小屋先预热，再返回星树开始本镜；实际手记必须在第 18 秒前显示，为阅读保留至少六秒，否则该镜头重拍。

## RTX 与录制

新服务、隧道、容器名称均与旧游戏分开。任务互斥；每次使用新的 Xvfb、Firefox、IPC 和输出目录。整页采集同时包含 WebGL 和真实界面文字。NVIDIA EGL 渲染与 NVENC 在运行时检测；编码不可用时回退软件编码。

剪辑使用 X11 实际采集起始时间和浏览器动作开始时间计算偏移，排除命令轮询与编码缓冲带来的片头空等，保留镜头尾部实际完成的动作。字幕安全区通过真实成片抽帧检查，避免盖住批注保存提示；录制、带字幕和无字幕版本分别验证时长与编码参数。

模型内嵌纹理需要浏览器读取 `blob:` 数据。私有录制页面允许同源、`blob:` 和 `data:` 资源，继续禁止外部检索；不能用白色模型代替加载失败的纹理。

GPU 算力仍与既有服务共享，因此独立容器隔离输入和数据，不承诺完全没有负载影响。取消、失败或服务重启只清理本任务标签及名称匹配的录制容器。

## 方法与边界

使用 `threejs-game-director` 的阶段组织与 QA 发布清单，以及音频制作参考；本轮按用户要求冻结美术，跳过模型生成和场景改造。旁白采用已确定的本机 Tingting，不引入额外语音服务。

作品介绍中的 Minecraft 指向共同建造的愿景，“黑神话”指向中国文化表达、审美与原创品质的追求。此次演示不增加多人共建、实时 AI 生成世界或完整大地体系，也不把这些愿景描述成现有功能。
