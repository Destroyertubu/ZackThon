# 漫思 Wanderwise 图文产品说明书

本版用于参赛项目介绍，重点说明 3D 第一人称交互式游戏的实际玩法、功能与工程架构。

- 主文档：漫思Wanderwise产品说明计划书（图文版）.md
- 13 张游戏实机截图：assets/live-*.png，正文使用的图片以 Markdown 引用为准。
- 3 张说明图：assets/01-*.svg、02-*.svg、03-*.svg；SVG 可编辑，附同名 PNG 方便上传。
- 额外保留少量全画面截图，供排版时选用。

## 图像来源

游戏图片于 2026 年 9 月 15 日在当前运行项目内截图，使用独立浏览器存档。阅读、收藏、批注、足迹、小屋手记、调酒与旅程拍摄均通过现有游戏功能操作。批注和足迹的局部图为实际界面截图。没有使用前端重绘或概念图替代实机画面。

玩法、工程架构与数据流图根据当前代码整理绘制，均在正文标注为说明图。AI 的在线可用性依赖部署配置，相关页面保留截图时的实际状态。

## 编辑与使用

编辑 Markdown 时保持 assets 文件夹与文档同级。文中的分页注释只控制 PDF 分页，不影响普通 Markdown 阅读。上传到项目介绍编辑器时，可按正文顺序上传实机 PNG 和说明图 PNG，再粘贴对应文字。

PDF 为 20 页排版版本；独立 HTML 已内嵌图片，可离线打开并点击图片放大。两者另行提供。本文所有功能表述以 2026 年 9 月 15 日代码与实机状态为准。
