# 星树收藏 · 2026-09-14

发布版本：`collection-tree-20260914-r1`。本轮只实现讨论稿中的收藏树，不改变首页入口、调酒配方或公共星系设计。

## 已实现体验

- 观星台主树保留现有模型、花池和通路。点击“我的星树”、按 T，或走到树旁按 E，进入临时看树视角。
- 原有收藏按来源首个有效标签归枝；无标签时用星系检索词，再回退到“未归枝”。五种旅程原料 ID 使用调酒台相同的中文名称；其他长标签完整保留。
- 每页六个主题、四片叶子。细枝连接现有模型的真实悬挂点，曲面叶子出现时轻微生长、发光；无矩形文字底板。
- 点击叶片使用已有静读界面。精选导读、来源节选、摘要和个人摘录分别标记，链接经过安全协议检查；没有下载到正文的材料不声称全文。
- 取消收藏不关闭阅读；在阅读中恢复时按原收藏记录 ID 恢复，不误合并同源摘录，不删除独立笔记。
- Esc 从静读返回树，再次 Esc 合上树。关闭后恢复原相机位置、朝向和画布焦点，可直接继续行走。T/E 不在其他面板内打开树。
- 零收藏有明确空态与“去星空摘星”入口。收藏仍属于当前浏览器的个人空间，不向公共服务发送或复制私人数据。

## 实现边界

`collectionTree.ts` 是已有个人库的只读投影；`restoreCollection` 只恢复内部记录快照，不引入新存储格式或导入入口。一次收藏仍对应一个叶子，同源不同摘录保留独立身份。现有持久层的导入校验保持原样；树内可展示运行时缺失来源的摘录，不代表放宽了不完整备份的导入规则。

`collectionTreeCamera.ts` 保存真实行走相机后才移动镜头。`capturePose()` 在看树期间始终返回原玩家位置，定时保存也暂停，因此从空态去星系不会把阅读相机当成返回坐标。

阅读期间继续使用同一个主要 WebGL 渲染器；没有新增 GLB、贴图或字体下载。背景场景继续轻微运动，移动控制与其他世界交互暂停。减少动态偏好关闭枝条生长和文字渐显，并直接定位相机。

## 验证记录

- 49 项个人数据测试全部通过，包含归组、中文原料名称、长标签、来源标识、安全链接、原 ID 恢复、重复历史记录及笔记保留。
- 5 项相机和实际 Rig 帧循环测试通过，覆盖精确位置恢复、减少动态、E 的优先级、禁止阅览位置写入存档、按键冻结和卸载清理。
- 观星台 19,108 个可站样本全部连通，15 次实际导航往返通过；自然鼠标和 85 种配方/比例回归通过。
- TypeScript、相关文件 ESLint、生产构建及生产 CSS 检查通过。构建仍有项目已有的大分块提示。
- 隔离开发来源 `127.0.0.1:4191` 通过正常旅程 UI 收藏四份真实精选材料，验证两个主题、静读、取消/恢复与双层 Escape。测试记录没有写入公网浏览器个人空间。
- 1280×720 与 390×844 视口检查通过；后者为浏览器响应式检查，不等同于实体手机性能验收。
- 连续十次开合后均恢复到画布焦点，采样纹理 151–154、几何 499–503，没有随开合持续增长。详情见 `artifacts/collection-tree/ten-cycles.json`。
- 本机开发会话在精细档约 14–15 FPS，开树和闭树均偏低，本轮不能据此声称本机达到 45 FPS。新增树控件的资源稳定性已经验证；总体场景性能需与生产/RTX 数据分别看待。
- 正式公网浏览器（Apple M5，精细档、1280×720）空树采样 29.7 FPS、P95 41ms；RTX 1080p 串流画面 59–60 FPS，服务器遥测确认 NVIDIA RTX PRO 6000、约 363 万三角形与 747 次绘制。这是不同运行档位的观测，不能互相替代。
- 刷新开发页面后四条收藏仍显示；正式公网入口无控制台错误；本地 4187 与公网发布标记均为本次版本。原有四个远端服务继续 active，未更换公网链接。
