# 星潮庭院、落日大道与镜海水面：实施交付审阅

状态：**r2 已发布；普通入口与云入口服务均 active，本机 dist 已同步。最终实机影像、云端精细档短时采样与关键往返验证已归档；性能和设备覆盖边界见下文。** 日期：2026-09-14。

本轮把观星台四周组织成连续庭院，重做落日大道的空间、建筑与近景材质，并替换共享海面的波形、反射和岸边过渡。以下区分已落地代码、已运行回归、资源估算和待完成验收；概念图及第一轮截图均不作为最终实机效果证明。

## 1. 本轮完成的场景修改

| 范围 | 当前实现 | 实现边界 |
| --- | --- | --- |
| 观星台 | 三段连续弧形花池连接阅读岸、回家花园与林间新月；弧形廊架、倒角木石收边、铜饰、攀援枝叶、低蕨和垂花形成低中高层次。三处海景开口和主要 2.5 米通道保留；灯具轻摆、植物风动和共鸣反馈沿同一庭院组织。月光、暖灯、材质与阴影统一调节。 | 保留原星树、调酒区、星门与回家门。新增庭院为参数化真实几何，约 12 个绘制批次；导出的 GLB 是可编辑交换资产，运行时不再额外下载一份。 |
| 落日大道 | 树荫入口 → 有纵深的书窗转角 → 水平桥面与下方拱券 → 半开放画廊 → 落日台。新增书店、工作室和画廊三套建筑，包含真实窗洞、室内纵深、书本、弧形屋顶和倒角细节。保留画作内容与五个停靠点。树干变细并弯曲，叶片缩小、叶簇加密；近景植物与花盆改为小叶、圆润花瓣及粗糙陶石材质。 | 桥面与主路保持 `y=0`，水位 `y=-1.1`；桥下有可见水道，但不能从桥下通行，也没有承诺坡道或多层导航。建筑内景是展示空间。其他九个旅程未整体重做。 |
| 镜海水面与海岛背景 | 多方向、多尺度 Gerstner 几何波与一致的解析法线，近处细波、远处衰减、Fresnel 反射、浅深水颜色、局部焦散、碎片状进退泡沫。岸线数据跟随实际岛岸及落日大道的道路支撑、建筑平台和树岛，桥下水道不被基础封死。瀑布末端连接水花或雾，浮岛、根系及弧形瀑布的几何稳定性有回归覆盖。 | 属于可控实时视觉模型，不是流体求解或完整水下折射。高画质使用节流的平面反射，流畅档关闭该额外渲染过程；反射随持续负载降级，切换场景释放所属资源。 |

落日大道铺石使用 2.5 × 2.5 米世界尺度 UV、2K 法线与粗糙度，并加入低频干湿差异。太阳/月亮位置、主光阴影方向和水面光路共用场景参数，减少此前光源与天空亮点不一致的问题。保留低亮环境填充，避免把发光和泛光当成所有材质细节的替代品。

主要入口代码：`GardenPerimeter.tsx` / `gardenPerimeterGeometry.ts`、`SunsetAssets.tsx` / `sunsetLayout.ts` / `worldGeometry.ts`、`MirrorWater.tsx` / `waterSurface.ts` / `waterReflection.ts` / `sceneArt.ts`。

## 2. 保存、导航与无框交互契约

十种配方和世界身份、原内容来源身份、五个落日停靠点 ID、个人收藏与笔记继续沿用。当前视觉改造不清空个人库，不把一次取消收藏当作删除独立笔记。JSON 导入导出、迁移重试和失败保护均已有回归证据。

`SceneReturnAnchor` / 保存视角仍用于往返恢复：有效位置与朝向保留；因新布景而失效或远离有效地面的旧位置，按该次旅程原停靠点寻找安全站位；缺失或非法记录才使用入口。新模型的实体位置同步提供碰撞边界。恢复函数覆盖幂等性、非有限数值和旧存档，不依靠随意把玩家丢回原点。

沿用进入场景即响应的自然鼠标视角、键盘和触屏；文字输入或阅读交互打开时暂停移动输入，恢复时避免镜头跳变。现有空间文字与无框阅读交互保留，本轮未用常驻文本框替换。降低动态设置继续控制环境运动。这些是代码与自动回归层面的保持；最终公网的逐项手动确认仍见下文待补表。

r2 公网交互已核对落日大道第三站 → 星系 → 返回：保留同一个 `trip`、第三站手记，关闭阅读后仍出现第三站的 E 交互入口，重新加载仍在第三站。`third-station-return.txt` 已更新为完整可访问性树，记录同一旅程 URL、`1 / 5` 进度、第三站“落日是否总是浪漫”选中及其 E 按钮。主任务同时执行收藏开关验证，并恢复测试前的未收藏状态。云端还实测了文学 60% / 摄影 40% 配方，点击调制后成功自动进入落日大道。
