# 旧生成入口移除与跳跃

## 行为与范围

移除“生成我的世界”“任凭天马行空”“继续上次旅程”所在的旧首页，以及 `/world` 的词云场景加载入口。首页 `/` 以 replace 导向小屋，旧 `/world` 导向镜海；画布改为“探索星系”。删除生成话题世界的 store 动作与生成函数。既有收藏、笔记、作品及兼容存档不清空。

小屋、观星台、镜海及十种旅程支持空格跳跃，Shift 仍是快走，E 仍是附近交互。手机显示向上箭头跳跃按钮。星系继续使用原本的空间浏览方式。

玩家目标是边走边观察、到达互动点；新增动作为短跳，没有战斗、得分或越界挑战。每次新按下触发一次，落地后才能再次起跳。空中按键不缓存到下一次落地；按住空格的系统重复事件不触发连续跳跃。实际键盘冒烟检查观察到约 14–46 ms 的首次响应，跳高约 0.645 m。

## 控制与物理

`jumpMotion.ts` 管理高度、竖直速度、脚下地面和落地状态。起跳速度 4.6 m/s，重力 16.4 m/s²；同高度落地约 0.56 秒。采用恒加速度的解析积分，单帧最大步长 50 ms，避免切回页面时瞬移。未引入物理引擎或额外刚体，不新增 collider；水平方向继续使用各场景原有的小步长碰撞代理和可行走区域。跳跃不允许穿墙、越过平台护栏或踏上未设为可行走表面的家具。

陆地控制先在地面位置上求解水平移动，再叠加腾空高度，避免把跳跃误判为跨越过高台阶。坡面变化期间保持空中世界高度；落地贴合当地地面。室内短跳的最高视点低于阳台门楣，镜头继续与玩家位置绑定。没有加入晃屏、FOV 冲击、额外粒子或声音；减少动态模式仍允许主动跳跃。

阅读、调酒、收藏及设置期间暂停移动和竖直积分；关闭后继续。失焦和隐藏页面清理按键意图，输入框和界面按钮正常使用空格。观星台与旅程保存地面位置，不保存暂时的跳跃高度；刷新、星系返回和旅程恢复仍使用安全落点。

## 验证

- `npm run test:jump`：20/30/60/144 FPS 的抛物线与落地、空中重复请求、坡面、异常帧、阳台双向跳跃通行、观星台边界、全部旅程返回落点。
- `npm run test:personal`：70 项通过，兼容存档不能恢复已移除的生成动作，收藏等已有动作保留。
- 小屋、观星台、陆地既有导航检查通过；自然鼠标控制检查通过。
- 浏览器真实输入：小屋、观星台、镜海、落日大道的空格起跳/落地/边走边跳；设置暂停、调酒文本中输入空格、空中刷新落地、旧入口跳转。
- 390×844 触屏：小屋、观星台和镜海的跳跃按钮，减少动态模式；没有 pageerror。
- 本地生产页面的首页/旧链接跳转与帮助键位通过；本地、公网和 RTX 构建哈希一致。GPU 串流端确认空格按下/释放包送达，连续画面可见起跳与落地；首次进场需等待场景加载完成再检查。
- 构建、截图、轨迹与检查日志位于本地忽略目录 `artifacts/jump-20260914/` 及 `artifacts/jump-*.log`。
