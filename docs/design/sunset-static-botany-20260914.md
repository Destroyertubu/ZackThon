# 落日大道：静态植物修正

本轮执行用户明确要求的植物修正。团队讨论稿另见 [差距分析](team-discussion-20260914-analysis.md)，其中功能建议没有自动实施。

## 已修改

- 删除落日大道的随机散叶程序树，换成完整的静态 Tree Small 02；七棵树高 6.6–7.2 米，根坐标、枝干、叶冠统一变换。保留原石质承台和所有停靠点 ID。
- 落日专用材质跳过植物顶点风动，不是冻结全局时钟。旧花池使用世界坐标 Z 计算摆幅，最大可造成约 1.2 米偏移；这条错误变形路径已移除。其他世界的风动、海水和云层继续使用原机制。
- 六处花池保留石木外形，改为围边、下沉种植面和完整根株。34 个候选落点排除距离树干不足 0.75 米的 4 点，实际放置 30 株白花植物及 30 株低矮蕨类。清除落日的漂浮花粉光点。
- 花池模型与碰撞读取同一布局；375 个小矩形覆盖旋转石箱，避免宽大的外接框占据通路。这些仅是 CPU 导航数据，不增加渲染网格。
- 同类植物按原模型部件实例化，共享几何与贴图。没有动画、蒙皮或变形目标；卸载仅释放实例及自有材质，保留加载缓存供再次进入使用。

- `scripts/test-sunset-planters.ts`：9,097 个检查通过，覆盖四处原先可深入石箱的坐标、实体边界、全部五站可达和全路 2.5 米净空。
- 原十一世界导航/几何回归：1,461 个检查通过。
- `scripts/test-static-botany.ts`：5 项通过，覆盖旋转层级的枝叶连接、真实高度与半径限制、缓存释放和重入、零高度拒绝，以及最终 GLB 的静态属性与 alpha 绑定。
- `scripts/test-visual-navigation.ts`：4 项通过，确认第三站星系回程及旧位置恢复仍有效。
- Draco 逐顶点解码与源几何对照：树 / 白花 / 蕨类最大位置误差分别约 0.0734 / 0.00446 / 0.01099 毫米。未减面。

- 生产构建与 CSS 编译检查通过。代码仍有原有大分块提示，本轮未把它视为已解决的性能问题。

构建、测试、修改前后实机图与发布日志位于 `artifacts/static-botany/`；模型正侧面图和解码记录位于 `artifacts/star-tide-upgrade/botany/`。实机截图不是概念效果图。

## 发布与回退

服务器发布标记：`static-botany-20260914-r1`。保留原公网地址、服务和用户数据，旧静态包保存在服务器 `artifacts/deploy-backups/static-botany-20260914-r1/dist-before`，旧源码为同目录 `src-before.tgz`。本地旧包保存在 `artifacts/deploy-backups/static-botany-20260914-local/dist-before`。

本轮 RTX 1920×1080 原始渲染的 9 个不同时间戳采样覆盖约 25 秒：平均 59.81 FPS，最低 58.9 FPS。普通浏览器 Apple M5 的 1280×720 流畅档已记录本次指标；这两段是短时验证，不代表全部设备或所有场景性能。

正式版已实际查看树冠全景和花池近景；固定镜头 16 秒录像 `static-plants-moving-sea.webm` 记录植物保持静态、海水继续运动。录制来自普通浏览器 WebGL，云端另有帧率采样，不混称为同一段录像。
