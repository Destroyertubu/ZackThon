# A+B 星潮花园与云瀑浮岛 · 实施记录

2026-09-13。已在现有 v4 工作树上实现并构建到本地生产服务，未执行 git push。此前尚未提交的镜海、内容服务、个人空间与十种旅程工作均保留。

## 当前效果

- 树前增加真实曲面月泉细渠：深色石盆、黄铜边、水面起伏、点击点向外扩散的涟漪，以及附近木地板上的动态水光。曲面外缘缩至 3.27 米，保留原有树前停留点。
- 调酒角增加曲面玻璃顶与黄铜拱肋、分层垂花和常春藤。花瓣使用实例绘制，另有稀疏飘落花瓣。
- 树前五枚悬挂玻璃星瓶分别对应五种知识原料；点击后打开调酒台并选入相应原料。沿用十种组合的真实旅程流程。
- 海上增加五座高低错落的浮岛、悬垂岩体与根须、十道曲面瀑布、穿岛云雾及不完整天然石环。远处云鳐间歇掠过，常态是低速环境运动。
- “唤起星潮”、靠近月泉按 E、点击池水均可触发环境回应；选择原料、开始调制时使用原料色。没有新增后台检索或 API 轮询。
- 共享环境时钟驱动波浪、瀑布、云层、花瓣与星瓶；阅读或调酒面板打开时，新环境运动降速，交互回应仍正常完成。系统减少动态偏好会冻结该时钟。

## 渲染与素材

新增远岛、月泉、玻璃棚、垂花、星瓶和云鳐均为实际几何或着色器，不以效果图覆盖场景。继续复用本地 Poly Haven 石壁、常春藤等素材及现有来源记录；本轮没有增加模型或纹理下载体积。概念图是艺术方向，截图是实际运行效果，二者仍有明显细节差距。

只使用当前场景的一个 WebGL Canvas。流畅档低频更新阴影，关闭导入灯笼的透射通道（源材质的黄铜也带有 transmission=1），避免重复渲染整座花园；玻璃原有透明度及环境反光保留。精细档保留实时阴影、AO 与辉光。抗锯齿使用 SMAA，避免与原生多重采样重复。

共享远景同时出现在小屋、镜海陆地和酒境；它不改变陆地碰撞、内容和旅程状态。近景新水渠的可视几何与碰撞来源相同。

- 新几何与时钟测试 2 项通过，覆盖所有浮岛/根须/瀑布/石环的有限坐标、索引和边界，响应重触发、衰减、后台恢复步长与减少动态。

- 实际浏览器：点击摄影星瓶选入“摄影 × 自然”，调好后自动进入露光标本，再从旅程返回观星台；正式页面的返回小屋及阳台入口另行检查。
- 正式 390×844 布局没有横向溢出，星潮按钮可触发状态提示。这是桌面浏览器尺寸测试，不是真机 GPU 测试。
- 本地 `/observatory`、`/land`、`/journey/dew-specimens` 及原公网观星台均返回 HTTP 200。生产预览未出现浏览器错误。

## 实际限制

当前电脑的 1280×720 流畅档记录约 29–52 FPS，重新进入后的两次记录为 51.6 与 39.7 FPS，仍未证明稳定达到此前 45 FPS 目标；精细/自动档更慢。阴影与透射优化已降低绘制开销，但现有高面数植物、多材质扫描件及灯光仍有成本。未将本次检查表述为十次连续切换或完整性能达标。

水面采用解析波纹、近景水光及远景简化倒影；没有全场景实时反射或体积流体模拟。不同浮岛/云层与远期细节仍可继续雕琢，当前画面不等同于概念图的一比一电影级效果。
