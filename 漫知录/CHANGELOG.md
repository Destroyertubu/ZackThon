# 版本更新记录

## v1.1.0 · 自由漫游与精神家园

发布日期：2026-09-08。Git 标签：`v1.1.0`。本版本汇总新版设计、知乎本地缓存和鼠标自然跟随的实现。

### 新增玩法

- 问题、话题词或随机种子启动世界；WASD 水平移动，Shift 上升、Ctrl 下降。
- 准星选取浮空文章片段：左键阅读、E 收纳、F 进入文章场域、V 追踪话题；Q 返回主世界。
- 精神家园四项设施：思维合成台、同频电话亭、漫行者日志、想法收纳柜。支持跨旅程归类、搜索、回顾与 2–4 来源合成。
- 锚点首次跨用户阅读增加共鸣；点击或长按连鸣，每人每锚点最多三次。评论与作者通知持久保存。
- 个人画布提供我的足迹、同频人足迹、全员热门小径，公共路径亮度与宽度取自主动公开的真实路线快照。

### 知乎内容与本地保存

- `python run.py --live` 使用已安装的官方 CLI 与系统凭据库，核对官方搜索字段并保留作者、原文链接与抓取时间。
- 搜索结果持久写入本地 SQLite，默认 `ZHIYE_CACHE_SECONDS=0`，不自动过期。相同查询跨访客复用，缓存命中不扣额度，并发查询合并。
- 保留旧版尚在数据库中的过期缓存。合法空结果也会缓存，上游错误不作为内容缓存；显式正 TTL 才启用自动刷新。
- 本地快照隔离演示与知乎内容模式，浏览器刷新恢复时保留来源标记。

### 交互与修复

- 进入探索后鼠标移动即转动视角，无需按住左键；打开面板暂停，关闭后恢复。Tab / Esc 释放，点击场景恢复。
- 浏览器无法提供 Pointer Lock 时支持自然鼠标跟随；触摸仍使用拖动。
- 文章场域保存与主世界轨迹隔离，返回时恢复位置、视角和缩放。
- 修复延迟锚点响应写入错误旅程、旧通知请求重新打开已关闭面板，以及跨世界节点 ID 冲突导致收纳话题错误的问题。

### 验证与兼容

- 39 项 JavaScript 测试、29 项后端测试通过，JavaScript 模块解析通过。
- WebGL2 完整流程及软件兼容模式回归通过；另完成鼠标跟随、面板暂停、释放恢复、触摸拖动的独立浏览器验证。
- 单次真实知乎搜索返回 6 条有效内容；重启服务、更换访客后复读命中本地缓存，访客与开发者额度增量均为 0。
- 自动迁移 SQLite 新增表与缓存保存时间；兼容旧版无高度存档，保留原访客 Cookie 与 IndexedDB 数据库名称。
- 已提供 Node 依赖锁文件、启动文档、可复现测试脚本和文件校验清单。

文章场域基于接口实际返回的摘要；知乎 OAuth、完整关注流、故事/知识接口、实时多人共游尚未接入。同频电话亭目前提供公开路线匹配，不是即时通话。公开锚点仍需审核。

本机 Chrome 原生 Pointer Lock 返回 `WrongDocumentError`，在最小空白页也可复现；浏览器验证证明兼容路径正常，不作为原生锁定成功的证明。未执行 Docker 构建、实体手机或生产压力验收。
