# 漫知录 v1.1.0 · 实现与验证

日期：2026-09-08。根据更新后的游戏设计，将原有问题探索原型扩展为自由飞行、文章场域、跨旅程家园与公共共鸣小径。

## 已实现的玩法

| 设计 | 实现 |
| --- | --- |
| 世界种子 | 接受问题、困惑、单个话题词或空白输入；随机开始生成实际种子并可存档 |
| 六向自由移动 | WASD 水平移动，Shift 上升，Ctrl 下降；鼠标转向、滚轮缩放，支持 WebGL2 和软件渲染 |
| 准星交互 | 话题附近出现浮空文章卡，选取屏幕准星实际命中的可见对象；左键阅读、E 收纳、F 进入场域、V 追踪话题 |
| 文章场域 | 按来源文本顺序拆成可探索的片段节点；Q/返回按钮恢复主世界位置、视角与缩放；场域移动不会写入主世界轨迹 |
| 想法锚点 | R 写自己的想法，T 阅读他人；首次跨用户阅读 +1 共鸣，点击或长按连鸣，每人每锚点最多三次；评论、通知持久化 |
| 精神家园 | H 返回家园；思维合成台支持 2–4 个跨旅程来源，柜子按原话题归类并可搜索，日志按时间汇总旅程、想法、洞察 |
| 同频电话亭 | 进入双方主动公开后的路线匹配与查看，不是即时通话或聊天 |
| 词云小径 | 个人画布提供我的足迹、同频人足迹、全员热门小径；公共热度根据实际公开路线的连续访问边聚合 |
| 实时内容 | 官方 CLI 使用系统凭据读取知乎；搜索结果持久保存到本地 SQLite，默认不过期，重复查询不消耗调用次数 |

设计中“漫行者日志”的描述尚未写完，本版按旅程回顾和思考时间线实现。思维合成使用已有的来源链接与个人解释流程，不会自动把生成的洞察标成原文引文或已证实事实。

家园在当前浏览器访客身份下汇总所有已保存旅程，并叠加当前尚未保存的修改。跨世界同名节点 ID 不会覆盖卡片原话题。旧版没有高度字段的存档按默认高度恢复，原有 Cookie、IndexedDB 数据库名称保持兼容。

浏览器回归使用独立 Uvicorn 服务、真实 HTTP、临时 SQLite、两个独立 Cookie 身份与原生 IndexedDB。验证开始旅程、键盘升降、准星收纳、卡片上滚轮缩放、场域保存隔离、追踪中断、面板暂停、合成和家园、另一个访客对已审核公共锚点阅读/连鸣/评论、作者通知、公共路径热度、刷新恢复，以及 390px 随机出发与家园布局。准星朝向由调试入口精确定位后验证实际键盘交互；未以自动化证明原生指针锁权限或实体手机触摸体验。

额外覆盖实际鼠标长按连鸣停止于三次，以及人为延迟真实 HTTP 响应时的隔离：旧旅程的锚点保存不会串入新旅程，已关闭的通知详情请求不会重新抢回面板。

公共内容测试使用临时数据库内创建的两位访客与测试审核入口；截图中的锚点和热门路径是测试数据，不是虚构的线上用户统计。浏览器测试始终使用原创演示内容；单次真实知乎搜索单独执行，不批量消耗额度。

## 复现

在项目代码目录中，激活已安装运行依赖的 Python 环境后执行：

```bash
python -m pip install -r requirements-dev.txt
npm ci
npm test
npm run check
python -m pytest tests/test_backend.py -q
python scripts/smoke_v11.py
MANZHILU_TEST_SOFTWARE=1 python scripts/smoke_v11.py
```

浏览器脚本默认使用 macOS Google Chrome；其他位置通过 `CHROMIUM_PATH` 指定可执行文件。真实搜索启动方法见 [LIVE_START.md](LIVE_START.md)。

## 当前边界

文章场域使用接口实际返回的内容，搜索摘要不会冒充完整文章。扩展话题仍基于可解释规则，没有接入模型生成语义图；思维合成保留用户主动解释。知乎 OAuth、完整关注流、故事/知识接口、实时多人共游尚未接入本作品。

锚点申请公开后需审核，公共路线需用户主动发布；私人内容不参与全员热度。当前是单服务进程与 SQLite 的原型部署，未执行多机压力测试、Docker 构建、实体手机验收或完整无障碍审计。

## 鼠标跟随修复

进入探索即启用鼠标跟随，不再要求按住左键。浏览器允许时自动使用 Pointer Lock；未提供或拒绝该 API 时，鼠标在场景内移动仍可转动视角。Tab / Esc 释放以操作界面，点击画布恢复；打开面板暂停、关闭恢复，触摸仍使用拖动。文章场域切换保留已有鼠标锁定。

新增两项事件回归测试，JS 共 39 项通过；WebGL 完整探索回归通过。独立真实浏览器测试覆盖无按键转向、面板切换、Tab / Esc、API 缺失/拒绝、CDP 触摸拖动。见 [smoke_mouse_look.py](../scripts/smoke_mouse_look.py)、[无头结果](../previews/mouse-look/browser-smoke.json)和[有头结果](../previews/mouse-look/browser-smoke-headed.json)。所有测试使用独立演示数据库，不消耗知乎额度。

本机 Chrome 的原生 Pointer Lock 在最小空白页同样返回 WrongDocumentError，画布连接与焦点检查均正常；上述浏览器结果验证自动跟随的兼容路径，不作为原生锁定成功的证明。
