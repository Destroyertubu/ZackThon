# 架构与技术决策

## 本版边界

实现依据为用户提供的 2026-09-09《漫知录 · Wanderwise 网页开发需求说明书》，视觉依据为《陆地方向 Three.js / 3D 开放世界素材清单》。镜头按需求书采用第三人称，不沿用素材清单中部分第一人称建议。以连续地面和实际道路表现语义邻近，不采用不可达的漂浮岛。

这些是明确披露的实现变更，而不是声称原建议栈已经接入。当前执行环境无法下载 npm 包、第三方模型及官方 Skill，使用本机已经可运行的技术路径完成交付。

| 需求建议 | 本版实现 | 代价与边界 |
| --- | --- | --- |
| React 19 / TypeScript / Vite / Zustand | 原生 JavaScript ES Modules + 集中语义状态 + DOM 面板 | 零前端安装与构建；没有 TS 编译期类型保障；需依赖 Pydantic、接口测试和有限状态约束 |
| Three.js / R3F / Drei | 自制 WebGL2 渲染器 | 单 Canvas，实际 GLSL 300 ES 着色器；不是 Three.js 适配，也不能直接使用 R3F 组件 |
| Rapier 胶囊物理 | XZ 圆形角色边界 + AABB 障碍 + 高度函数 + 重力 | 基础行走/跳跃/避障；不是完整刚体、胶囊扫掠、复杂斜坡与台阶系统 |
| Troika SDF | 系统字体光栅化 + 距离场纹理 + SDF Shader | 不分发字体文件；距离场创建同步，未做 Worker 预热；长中文场景可能有卡顿，待实测 |
| Blender → GLB | 代码程序化低模几何 | 自制角色、植物、设施、地形；不是已导入 KayKit/Liu 看山；没有 Blender 源文件 |
| 实例化 / 分块地形 | 静态几何合批、文字距离分层、纹理 LRU | 没有完整分块流式卸载；50 节点上限场景仍须测量 CPU/GPU/内存 |
| SQLAlchemy / Alembic | Python sqlite3 + 事务 + schema_version=1 | 没有 ORM/自动迁移框架；后续升级需显式迁移并备份 |
| LLM 语义抽取/论证场域 | 标题/标签与真实段落驱动的规则布局/规则结构导览 | 关系只表示阅读方向，不声称因果或已识别作者论证；不是完整 AI 论述分析 |
| 2–4 材料 AI 合成 | 真实 AI 适配器 + 显式手工模式 | 无凭证默认手工空白草稿；AI 输出校验不过即失败，不伪造生成 |
| 全部 P0 公网验收 | 本地可启动工程及分层测试 | 缺少真实提供器、公网、浏览器 3D 和性能验收，不标 P0 全过 |

## 运行数据流

```text
浏览器：DOM 界面 + 单个 WebGL2 Canvas
      ↓ 同源 /api/v1（Cookie / CSRF / Idempotency-Key / X-Client-Id）
FastAPI + Pydantic + 权限 / 版本 / 幂等层
      ├── SQLite：访客 / 世界版本 / 旅程 / 收藏 / 锚点 / 洞察
      ├── 持久任务表 + 2 个有界工作线程
      ├── 共享提供器缓存 + 应用层日预算
      └── 固定知乎域名提供器
            ├── 搜索：摘要，不是假全文
            ├── 活动知识：从真实目录拿 work_id 再请求正文
            └── 直答：显式触发，校验材料 ID 与输出字段
```

`frontend/engine/` 只处理几何、运动、文字、导航和选取；`app.js` 管理场景语义、覆盖层、按钮、API 结果和旅程；`storage.js` 管理 IndexedDB 草稿、缓存和未确认操作。逐帧位置不通过 DOM 状态重绘。

`backend/app/providers.py` 只访问固定提供器地址，不抓取用户提供的任意 URL；`worldgen.py` 处理来源、规则话题、确定性布局和段落场域；`jobs.py` 记录实际阶段；`main.py` 校验身份和资源归属，写入成功提交事务后响应。

## 内容、世界与来源约束

外部 ID 永远是字符串。来源清洗去掉不受信任 HTML，保留安全原链接及追踪参数。正文切段产生段落 ID、起止位置；摘录引用快照并校验精确范围。全文、章节、摘要具有不同 coverage。只有拥有相应世界或收藏的访客能读取来源。

世界保留 layoutSeed、layoutVersion、sourceSnapshotSetId、snapshotMap、节点/道路、version。初始演示路线 7 个节点，扩展追加候选且不移动原节点；去重和上限可使新增为 0。道路类型在本版扩展为 `path`，因为是连续陆地步道。与需求示意中的 bridge/slope/portal 枚举有差异，消费者以随包代码与样例为准。

段落场域最多选 8 个段落节点。长文明确标示处理范围；章节不称整部作品。这里是规则性的正文导览，不把段落排序当作已经完成 AI 论点/论据识别。

世界快照读回按缓存展示；original demo 永远保留 demo。真实缓存不会因恢复旅程而重新标成今日或实时热点。

## 可靠性与安全

访客 Cookie 为不透明随机值，数据库存散列，HttpOnly、SameSite=Strict；HTTPS 部署开启 Secure。所有私有资源按当前访客过滤。写操作检查 Origin 与 CSRF；变更幂等键绑定用户与请求摘要；锚点/收藏/检查点使用 expectedVersion。检查点同时持有标签页写入租约，显式接管会使旧版本失效。

数据库开启 WAL、外键和短事务；一次只运行一个服务实例。任务在重启后标记中断，不自动重发可能已计费的上游请求。客户端任务轮询不会重新调用提供器。

幂等确认保存 24 小时；访客无活动 30 天后清理；未保存洞察草稿 24 小时清理。分析性语义事件与私人文字不同，不拿精细移动轨迹做社交画像。

## 已知不足，不通过描述替代实现

没有生产级防滥用网关/验证码/可观测告警。Origin/CSRF 不是完整互联网防护。分页目前为服务端整表过滤后的有限分页，不适合大规模用户。数据库和业务错误的若干极端失败仍可能返回框架 500，需要上线前故障注入。

IndexedDB 队列能保留已加载会话中的草稿/待提交写入，但没有断网冷启动保证；浏览器级离线冲突、崩溃重放未实测。事件 ID 已去重，但需求书的所有 3 秒来回抖动统计规则尚未逐项完成。星图是语义步骤，不是动作录像。

本版没有完整 TypeScript 响应模型；OpenAPI 由实际 Pydantic 请求模型生成，部分通用 JSONResponse 的响应细节需结合实现和 fixture 阅读。后续可在保留领域模型与 API 的情况下迁移到 React/R3F/Rapier。
