# 体验与演示脚本

## 不需要 API key 的演示

启动后进入小屋，辨认大门、收纳柜、合成台、日志和未开放的电话亭。下方按钮是全部核心设施的可访问入口，避免只靠走路找到操作。

从大门选择“原创演示”路线。显示自制数据标识，不声称来自知乎。按“进入漫游”后移动；靠近金句直接左键打开原文。当前版本已删除简化阅读模式。

读一段，检查来源类型、范围和时间，收集两个不同片段。重复收集同一片段应提示已收录，不增加第二条。留下一个私人锚点，随后从锚点管理检查、编辑或删除。

对于自带正文点击 F 场域入口。每个节点对应实际段落，不是摘要虚构全文。用常驻返回按钮恢复主世界。对一个未扩展节点展开新方向，查看旧节点坐标保持、新道路与新话题出现；重复展开不会无界调用。

保存回家，打开收纳柜，选择两份有证据的材料，可先建立手工连线，再送往合成台。没有服务端凭证时，选择手工联系、写下自己的理解并保存；不要把手写模式解说成 AI 自动推理。

打开日志，看洞察和语义星图；刷新页面，确认已保存条目仍存在。继续暂停旅程或明确结束归档。电话亭只说明后续玩法，不用随机头像或虚构相似度演示。

## 切换到正式知乎演示

先按照 API_VERIFICATION.md 完成真实目录/搜索/正文联调，并留下脱敏报告。使用正确来源的缓存路线保障演示稳定，显示获取时间。缓存不是实时热榜。实际 AI 生成要先核验可用型号、响应格式、引用 ID 与额度。

## 上台前仍需执行的检查

真实桌面浏览器：第三人称可见、移动、碰撞、跳跃、鼠标锁定/退出、输入法隔离、文字清晰、正文场域返回。真实网络：Cookie/Origin/CSRF/跨访客隔离，持久卷重启，429/超时/离线。基准设备：20 次生成、3 分钟帧率路线、10 次场景往返与20分钟内存。至少3名非开发者体验。
