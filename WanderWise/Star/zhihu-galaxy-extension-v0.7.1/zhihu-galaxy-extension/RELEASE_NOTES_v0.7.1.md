# Zhihu Semantic Galaxy v0.7.1

## 本次改进

1. **悬浮原文信号改版**
   - 去掉原先的消息框式 hologram 卡片。
   - 改为由回答节点引出折线，拐弯后形成平行引导线，原文选段以发光悬浮文字的形式漂浮在空间中。
   - 仍保留点击原文信号跳转/聚焦能力。

2. **新增“谱系染色”节点配色模式**
   - 基础关键词节点：稳定随机染色。
   - 话题/交汇节点：按相关关键词颜色做渐变融合。
   - 具体文章/回答节点：继承所属话题的平均色；若同时关联其他话题，则从相关话题中稳定选取一种代表色。
   - 与既有三套心情主题（科技深黑蓝紫青 / 饱和橙砖青绿 / 莫兰迪）并存，可在设置页切换。

3. **三维交互键位增强**
   - `WASD`：转动视角。
   - `Space`：远离。
   - `Shift`：拉近。
   - 左键单击：关注节点并点亮其相邻点。
   - 左键双击：聚焦该节点并自动拉近到能看清其直接关联分支。
   - 右键：标记为“仔细阅读”，弹出评论框写入记录；回答节点备注会同步到收藏/行囊笔记。

4. **回答节点收缩**
   - 收紧回答节点与上一级节点之间的空间距离。
   - 同时收缩力布局中回答边的理想长度，降低末端过度发散问题，更容易看出文章围绕哪些话题。

5. **AI 校对设置入口保留**
   - 仍支持扩展独立设置页中配置 AI 供应商与 API Key。
   - 本地语义可继续作为 fallback。
