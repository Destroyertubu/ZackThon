# 空间与知识结构

`content.js` 从当前知乎页面/同源接口/可选新版本地 bridge 渐进取得真实回答。`engine.js` 做清洗、纯算法主题提取和语义图构造。`core.js` 保留稳定 nodeId、回答索引、轨迹 v1 数据契约。`experience.js` 提供基础阅读/行囊/导入导出能力；`galaxy3d.js` 覆盖渲染、镜头和设置行为；`spatial.js` 是纯三维几何/力布局；`ai-client.js` 只改通过证据校验的语义邻接。

引力：回答-父主题、观点-父主题和少量共证据主题连边上的弹簧。斥力：XYZ 空间哈希近邻的距离衰减力。弱锚定限制漂移，阻尼和有限迭代使空间趋于静止。引力/斥力是控制图密度的参数，不是物理质量。新增回答保留已有节点身份和作为起点的位置；力布局启用时，之后可能继续微调坐标。冻结则不运动。

节点投影严格是相机坐标中 x/z、y/z 的透视映射，没有屏幕空间位移。文本平面由 origin、axisX、axisY 定义，再组合成 CSS matrix3d 与同一相机一致的射影变换。平面中心在回答的真实世界位置上方，平面大体面向观察者，轻微倾斜，产生透视宽度与视差。Canvas 画后方节点、连线和轨迹；DOM 画可选择点击的原文平面；前景 Canvas 重绘真正位于平面前方的球体。没有用飘动的屏幕截图假冒三维。

文本优先级：选中/指向/固定的回答优先；其它候选有短期保留；原文相同则去重；依照面板预算及视锥/屏幕占用裁剪。次要标签隐藏而不挪位置，因此进入某些视角时能看到的标签数不同。贴近可看得更大，但不会为了保证所有面板常在屏幕内而破坏世界位置。

轨迹是语义到访序列，不是鼠标录制。世界中的弧线连同一问题、同一 session 的相邻 visit；收藏增加节点标记。快照记录世界位置但允许 UI 通过稳定 ID 回到更新后的位置。画像占位接口输出 `not_implemented`，观测和向量为空；未来需独立授权和新 schema 版本，不能把停留时间直接解释为赞同或人格。
