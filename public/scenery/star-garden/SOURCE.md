# NASA star background

Runtime file: `milkyway-nasa-4k.jpg`, 4096 × 2048, sRGB JPEG.

Source: [Deep Star Maps 2020](https://svs.gsfc.nasa.gov/4851/), NASA/Goddard Space Flight Center Scientific Visualization Studio, Ernie Wright.

Downloaded original: [milkyway_2020_4k.exr](https://svs.gsfc.nasa.gov/vis/a000000/a004800/a004851/milkyway_2020_4k.exr).

The SVS publishes its content in the public domain unless otherwise noted: [SVS information and use policy](https://svs.gsfc.nasa.gov/help/). This background contains no logo, identifiable people, or constellation illustration overlays. Star catalogue acknowledgements and production credits remain on the source page.

Derivative: the official linear EXR was converted with Blender to a 92-quality JPEG using the Standard view transform. The runtime shader places it above the existing CC0 Kiara valley, lowers its brightness, and applies an artistic blue-hour tint. It is a decorative sky orientation, not a planetarium pointing solution. Original EXR was downloaded on 2026-09-13 to the temporary asset cache; the deployed application makes no NASA network requests.
